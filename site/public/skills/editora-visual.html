Transforma o copy aprovado em carrossel pronto, pelo caminho que a pessoa escolher: slides em HTML montados no próprio chat, com botão para baixar cada slide em PNG 1080x1350, ou o texto aplicado no template do Canva pelo conector. O que ela faz

Transforma o copy aprovado em carrossel pronto, pelo caminho que a pessoa escolher: slides em HTML montados no próprio chat, com botão para baixar cada slide em PNG 1080x1350, ou o texto aplicado no template do Canva pelo conector. Sem o conector do Canva, entrega o copy slide a slide para colar manualmente.

Quando usar

  • Use depois do copy pronto, quando a pessoa pedir para montar a arte, gerar as imagens do carrossel, aplicar o texto no template ou finalizar o post.

O que ela pergunta

  • Como você quer montar o carrossel: aqui no chat, em HTML com PNG para baixar, ou no seu template do Canva.
  • O copy aprovado, slide a slide, vindo da redatora-copy ou colado por você.
  • Cores, fontes e o seu @, só se o seu contexto de marca ainda não trouxer essas informações.
  • No Canva: o link de uma cópia do seu template. Sem o conector, ela entrega o texto pronto para colar.
