# Kit de Skills · Imersão Claude 2.0

Kit completo de skills e assets para o programa Imersão Claude 2.0.

## Avisos importantes

As páginas e pacotes em `site/public/` são GERADOS por `npm run build`, nunca editados à mão.

## Instalação

Baixe o repositório [https://github.com/aline-delamare/kit-imersao-claude](https://github.com/aline-delamare/kit-imersao-claude) (se o git não estiver disponível, baixe e extraia [https://github.com/aline-delamare/kit-imersao-claude/archive/refs/heads/main.zip](https://github.com/aline-delamare/kit-imersao-claude/archive/refs/heads/main.zip)) e instale cada pasta de `skills/` como skill global do Claude Code (uma pasta por skill, cada uma com seu `SKILL.md`).
